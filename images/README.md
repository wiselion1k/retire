# 사진 넣는 곳

> **현재 들어 있는 이미지는 실제 사진이 아니라 Blender(Cycles)로 직접 렌더링한 이미지입니다.** 저작권 문제가 없도록 처음부터 직접 만들었고, 도시별 실제 풍경이 아니라 장면 종류(해변·섬·산·도시 야경)별로 분위기만 맞춘 대체 이미지입니다. 실제 사진 파일로 같은 이름으로 덮어쓰면 그대로 교체됩니다.

이 폴더에 사진 파일을 넣으면 페이지의 일러스트가 **자동으로 사진으로 바뀝니다.**
파일이 없으면 지금처럼 일러스트가 보이므로, 필요한 것만 하나씩 넣어도 됩니다. 코드 수정은 필요 없습니다.

## 필요한 파일

| 파일 | 어디에 쓰이나 | 권장 크기 |
|---|---|---|
| `hero-retire.jpg` | 은퇴이민 페이지 맨 위 큰 이미지(나라별 사진이 없을 때 기본) | 가로 1920px 이상, 가로형 |
| `hero-travel.jpg` | 여행 비교 페이지 맨 위 큰 이미지 | 가로 1920px 이상, 가로형 |
| `countries/kr.jpg` `my.jpg` `sg.jpg` `au.jpg` | 은퇴이민 페이지에서 나라를 고르면 맨 위 이미지가 그 나라 사진으로 바뀜 | 가로 1920px 이상, 가로형 |
| `cities/<도시id>.jpg` | 도시 카드, 도시 둘러보기, 승자의 여정 큰 이미지 (아래 표) | 세로 4:5 비율, 가로 1000px 이상 |

도시 사진은 카드(세로 4:5)와 풀블리드(가로) 양쪽에 쓰이므로, 중앙에 피사체가 오는 사진이 가장 안전합니다.

## 사진 고르는 기준
- 무료 상업 이용이 가능한 곳(Unsplash, Pexels 등)이나 직접 찍은 사진을 쓰세요. 다른 사이트나 앱의 화면을 캡처해 쓰면 저작권 문제가 생길 수 있습니다.
- 용량은 장당 300KB 안팎(JPG, 품질 75~80)으로 줄이면 페이지가 빠르게 열립니다.
